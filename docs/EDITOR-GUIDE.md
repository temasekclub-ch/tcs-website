# How to update the website

You do not need to know anything about websites or code. Everything you can change lives in one **Google Sheet** called **TCS website content**. The website reads the sheet every time someone opens a page, so when you change a row and reload the website, the change is there.

Ask the website's administrator for access to the sheet if you cannot open it.

---

## The golden rules

1. **Only change the rows, never the top row.** The coloured first row of each tab (the headers) tells the website what each column means. Do not rename it, move it or delete it.
2. **Do not rename the tabs** at the bottom of the sheet.
3. **Do not leave blank rows in the middle.** Add new rows directly under the last one.
4. **Never type private information.** Anything in this sheet can be read by anyone who finds the website's data address.
5. If you are unsure, use the menu **TCS website > Check my content for problems**. It points out blank names, broken links and similar slips.

## Everyday jobs

### Change a word or a name
Click the cell, type the new text, press Enter. Reload the website to see it.

### Add something new (a person, a sponsor, an event...)
1. Go to the tab.
2. Click the first empty row under the last entry. Copy the row above (select it, Ctrl/Cmd+C) and paste it into the empty row (Ctrl/Cmd+V) if that is easier, then change the words.
3. The **Show** box is already ticked in empty rows. Leave it ticked.

### Hide something without deleting it
Untick its **Show** box. It disappears from the website. Tick it again to bring it back.

### Change the order
The **Order** column is a number. 1 comes first, then 2, and so on. Rows with no number come last. You can use any numbers: 10, 20, 30 leaves room to slip something in between later.

### Move someone from Current to Past
On the Team or Sponsors tab change **Status** to Past. For past team members you can write their roles with years, for example `President (2023–2025)`.

### Move an event from Upcoming to Past
1. In **Events** untick Show (or delete the row).
2. In **Past Events** add a row with the **Year** (for example 2026), the date, title and tag.
3. If you want a button on this event, paste its web address or Drive link into **Link** and type the words for the button into **Button text** (for example "Download meeting minutes"). The button only appears when both are filled in. Leave **Button text** empty and no button is shown.

### Add a photo or logo
1. Upload the photo to the club's shared Google Drive folder.
2. Right-click the photo, choose **Share**, set General access to **Anyone with the link**, and click **Copy link**.
3. Paste the link into the **Photo** or **Logo** cell.

Tips: for people use a square photo. For the home page carousel use a wide photo (landscape). Do not share the *folder* link, share each photo's own link.

### Add an AGM or other document
In **AGM Docs** add a row with a title (for example AGM 2027), a date, and the link to the document. Upload the PDF to Drive, share it with "Anyone with the link", and paste that link into **File link**.

### Change the home page carousel
In **Home Carousel** each row is one photo. The **Caption title** and **Date** appear under the photo and change as the photos change. Type the date without the word "on", the website adds it.

### Change the "Events across the year" photos
In **Home Event Photos** each row is one photo. The **Event type** column groups them: all rows of type "Ski trips" become the photos under the Ski trips button. Put an emoji on the first row of each type. To add a new button, simply use a new Event type name.

### Change bits of text on the About and Life in Switzerland pages
Use the **About** and **Life Tips** tabs. Put two asterisks around words to make them **bold**, like `**this**`. Press Alt+Enter (Windows) or Ctrl+Option+Enter (Mac) inside a cell for a new line.

### Change the social media links at the top of the page
Open **Settings** and change the address next to instagram, facebook or linkedin.

## Messages from the "Join us" form

When a visitor sends a message it arrives in the club's email (temasekclub.ch@gmail.com) and is also saved in the **Messages** tab. Press Reply in Gmail to answer: it goes straight to the visitor.

## If something looks wrong

| Problem | What to check |
|---|---|
| My change does not show | Reload the website (hold Shift and press reload). Wait a few seconds. |
| A row is missing | Is Show ticked? Is the first column (Name or Title) filled in? Are the tab and header names untouched? Run **TCS website > Check my content for problems**. |
| A photo shows a grey picture | The Drive photo is not shared with "Anyone with the link", or you pasted a folder link. |
| Weird characters or layout | Remove odd formatting: select the cell and use Format > Clear formatting. |
| Everything is broken | Do not panic. Use **File > Version history > See version history** in Google Sheets to go back to an earlier version, then tell the administrator. |
